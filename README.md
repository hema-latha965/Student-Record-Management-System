
# Student Record Management System

## Project Description
The Student Record Management System is a menu-driven application developed using C programming. It uses a Singly Linked List (SLL) to manage student records dynamically.

The project allows users to add, display, delete, modify, sort, reverse, and save student records.

## Features
- Add student records with automatic roll number allocation.
- Display all student records.
- Delete records by roll number or name.
- Modify student details.
- Sort records by name and percentage.
- Reverse the linked list.
- Delete all student records.
- Save records into a file.
- Load previously saved records when the program starts.
- Free dynamically allocated memory.

## Technologies Used
- Programming Language: C
- Compiler: GCC
- Data Structure: Singly Linked List
- File Handling
- Dynamic Memory Allocation (DMA)

## Project Files
- `stud_main.c` – Main menu and program execution.
- `stude_add.c` – Add student records.
- `stud_del.c` – Delete student records.
- `student_show.c` – Display student records.
- `student_mod.c` – Modify student records.
- `stud_save.c` – Save and load student records.
- `stud_sort.c` – Sort student records.
- `stud_delete_all.c` – Delete all records.
- `stud_reverse_links.c` – Reverse the linked list.
- `stud_free.c` – Free allocated memory.
- `student.h` – Header file containing structure and function declarations.
- `Makefile` – Compilation instructions.
- `student.dat` – Saved student records.
- `student` – Compiled executable.

## Compilation and Execution

Compile the project:

```bash
make
```

Run the application:

```bash
./student
```

Clean generated object files and executable:

```bash
make clear
```
